Requires ts-pf 1.0. Every `@ts-pf/*` peer is now `^1.0.0` (was `^0.6.0`): `@ts-pf/contract`, `@ts-pf/docs`, `@ts-pf/mcp`, `@ts-pf/protocol` and `@ts-pf/server`. This is a breaking change: an app on ts-pf 0.6 upgrades its `@ts-pf/*` packages to 1.0 with Lattice. Lattice's own API is unchanged.
