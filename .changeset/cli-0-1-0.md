First release. The `lattice` command, with `lattice collection <slug>`: it writes a collection and its test, registers the collection in the app's `framework()` chain, and lists its events in the app's `EventCatalog()`. It parses the app's files with the app's own `typescript` and inserts text where the file's shape gives one place for it. It keeps the file's comments, line breaks and indent. On any other shape it writes nothing, exits 1 and prints the lines to add by hand. It writes every file or none. `--dry-run` prints a diff. `lattice migration <name>` writes the next numbered migration and appends it to the app's list, by the same rules. `lattice migrate` imports the app's built `{ store, migrations }` module and runs store-mongo's `migrate()`. Paths come from an optional `"lattice"` key in `package.json`, which defaults to the crm's layout.

Install it with its peers: `npm install --save-dev @latticecms/cli`, beside `@latticecms/core` and `typescript`. See the [README](./README.md#install).
